# Контексты (DDD)

Шесть ограниченных контекстов. Каждый знает только свои термины и не лезет в чужие.
Зависимости - сверху вниз, обратных нет.

```
Workspace (вкладки, сессия, файлы проекта)
    ↓
Editor Core (буфер, курсор, выделение, транзакции)
    ↓
Presentation (layout, render, overlay, theme, тосты)
    ↑
Input (клавиши, мышь, фокус)
    ↓
Language Services (LSP, диагностики, completion, фиксы)
```

`Assist` (ghost, t9, будущий AI) стоит рядом с Language Services и использует те же
события - но не владеет буфером.

## Workspace

- Открытие файла, проект, недавние, вкладки, сессия/state.
- Не знает про LSP и отрисовку.
- События: `FileOpened`, `TabClosed`, `SessionChanged`.

## Editor Core

- Буфер: строки, EOL, версия, dirty; курсор и выделение; транзакции и undo.
- Единственное место, где меняется текст.
- Не знает про клавиши и цвета.
- События: `Changed`, `Saved`, `CursorMoved`, `SelectionChanged`.

## Presentation

- Раскладка (layout), рендер видимого, слой оверлеев, тема, тосты, статус-бар.
- Читает состояние, ничего не меняет в буфере.
- Знает про [[Примитив - Popup]] и [[Примитив - Курсор и выделение]].

## Input

- Клавиши и мышь, фокус (текст / строка ввода / попап), маршрутизация.
- Превращает события в команды домена, не в правки напрямую.
- Порядок: help → popup → input → текст.

## Language Services

- Запуск серверов, JSON-RPC, диагностики, completion, code actions, format.
- Не блокирует UI: всё через сообщения в цикл.
- Владеет кэшем диагностик по документу (как в micro-плагине).

## Assist

- Ghost и t9: собирает кандидатов, решает, что показать; цифровые подсказки.
- Ничего не пишет в буфер сам - возвращает «принять» через Editor Core (транзакция).
- Позже: AI-дополнение предложений тем же путём (только в completion/ghost, без отдельной
  кнопки - см. [[Решения]]).

## Правила

- Контекст не импортирует внутренности другого; общение - через события/команды.
- Presentation никогда не меняет модель.
- Editor Core не знает, что такое LSP.
- Любая внешняя система (LSP, ОС) - за интерфейсом, чтобы тесты шли без процессов.
