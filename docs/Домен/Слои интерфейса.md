# Слои интерфейса

Ты прав: то, что я называл «экранами», - это в основном примитивы экрана. Уточняем
термины, чтобы не путаться.

## Уровни

| Уровень | Что это | Примеры |
|---|---|---|
| **Экран** | всё, что занимает терминал целиком | [[Экран - Редактор]] - единственный постоянный |
| **Зона** | прямоугольник внутри экрана | полоса вкладок, гаттер, текст, статус-бар |
| **Примитив** | переиспользуемый элемент | [[Примитив - Курсор и выделение]], [[Примитив - Popup]], [[Примитив - Строка ввода и список]] |
| **Оверлей** | временный слой поверх экрана | completion, quickfix, Ctrl-P, помощь |

«Экран - Вкладки» - на самом деле зона, а «Экран - Completion» - оверлей. Названия
оставили как есть, чтобы не переименовывать ссылки, но в тексте они описаны по уровням.

## Как это собирается

```
Экран (терминал)
├── зона: полоса вкладок        ← вкладки
├── зона: гаттер (номера строк)
├── зона: текст                 ← курсор, выделение, диагностики, ghost
├── зона: статус-бар
└── оверлей (0 или 1)           ← popup / строка ввода / помощь
```

- Оверлей всегда один (v1), он забирает клавиши первым.
- Зоны не перекрываются, оверлей - может.
- Мышь работает и по зонам, и по оверлею ([[Мышь]]).

## Модель вкладки (как ты её описал)

- **Вкладка = буфер = файл.** Не «панель», не сплит.
- Новая вкладка (`Ctrl-O`) открывается пустой и сразу показывает выбор файла ([[Экран - Открытие файла]]).
  Выбрал файл - буфер заполнился; `Esc` - остаётся пустой безымянный буфер, можно писать.
- Открытие файла (`Ctrl-P`) - тоже новая вкладка; если файл уже открыт, переключаемся на него.
- Закрытие (`Alt-Q`) закрывает вкладку; грязную - спрашивает.
- Пустых «заготовок» в фоне нет: вкладка либо с файлом, либо явно безымянная.

Это подтверждает [[UX-принципы]]: один экран, вкладки вместо сплитов.
