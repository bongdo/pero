# Prose и Code

Редактор один, поведение - разное. Режим определяется типом файла и может быть переопределён
в конфиге.

## Определение режима

| Тип | Режим |
|---|---|
| `.md`, `.markdown`, `.txt`, `.rst`, `.org` | **Prose** |
| `.go`, `.js`, `.ts`, `.rs`, `.c`, `.h`, `.lua`, `.nix`, `.nim`, `.py`, `.sh`, `.mojo` | **Code** |
| `.json`, `.toml`, `.yaml`, `.yml`, `.ini` | **Code** (без LSP, если сервер не настроен) |
| неизвестное | **Plain** - как Code, но без LSP и подсветки |

Переопределение: `[files] "*.md" = "code"` в конфиге.

## Матрица поведения

| Фича | Prose | Code |
|---|---|---|
| Softwrap | вкл ([[Softwrap]]) | выкл |
| Спеллчек | ltex (ru) / harper (en) | выкл |
| Markdown-чекбокс `Alt-t` | вкл | выкл |
| Продолжение списков | вкл | выкл |
| `Alt-s` (пробелы) | вкл | выкл |
| Completion | слова из буфера (t9) | LSP |
| Ghost | t9 (слово) | LSP |
| Диагностики | ltex/harper | LSP языка |
| Подсветка синтаксиса | markdown | язык |
| Автоотступ | по списку | по языку |
| Табы | пробелы | по `tabsize`/языку |

## Почему так

- Проза: главное - читать и писать текст; перенос и грамматика важнее структуры.
- Код: главное - структура; перенос строк ломает восприятие, спеллчек - шум.

## Спеллчек

- Русский: `ltex-ls` (LanguageTool), старт 6-8 секунд - не блокирует ввод.
- Английский: `harper-ls`, быстрый.
- **Авто по содержимому**: при открытии prose-файла смотрим первые 4-8 КБ; если доля
  кириллицы заметная - поднимаем ltex, иначе harper. Запускаем **только один** сервер,
  второй не грузим.
- Ленивый старт: сервер поднимается после короткой паузы (300 мс), чтобы открытие файла
  было мгновенным; до готовности - статус `LSP…`.
- ltex стартует долго: если за 8 с не ответил - статус `ltex: нет ответа`, текст живёт.
- Диагностики ltex - уровня info, подчёркивание приглушённое ([[Примитив - Диагностика и ghost]]).
- Переопределение: `[markdown] spell = "ltex|harper|off"` в конфиге.

## Крайние случаи

- README с кодом внутри (```` ``` ````): спеллчек не должен ругаться на код - ltex это умеет,
  harper - нет; решение за сервером.
- Файл без расширения, но с текстом: по содержимому (много кириллицы/пробелов → Prose?).
  v1: `.md`/`.txt` только.
- Смешанный файл (`.md` с русским и кодом): режим Prose, но подсветка markdown + блоки кода.
- `Shift-Enter` внутри prose - обычный перевод строки (см. Backlog: micro-баг).

## Критерии готовности

- [ ] В `.md` переносы и чекбоксы, в `.go` - нет.
- [ ] В `.md` работает t9/ghost из слов, в `.go` - из LSP.
- [ ] Спеллчек не появляется в конфигах.
- [ ] Переопределение режима в конфиге работает.
