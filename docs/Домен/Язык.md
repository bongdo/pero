# Язык (ubiquitous language)

Один термин - одно значение. В коде, в UI и в этой базе.

| Термин | Значение |
|---|---|
| **Буфер** | текст одного файла в памяти: логические строки, EOL, версия, dirty-флаг |
| **Документ** | буфер + путь на диске (или «без имени» для нового) |
| **Вкладка** | открытый документ в полосе вкладок; одна вкладка = один документ |
| **Проект** | корень для поиска файлов и LSP (git/jj-корень или cwd) |
| **Курсор** | логическая позиция (строка, руна) |
| **Выделение** | якорь + курсор, полуинтервал `[anchor, cursor)` |
| **Транзакция** | группа правок, которая откатывается одним undo |
| **Диагностика** | диапазон + сообщение от LSP (error/warning/info) |
| **Фикс** | правка (WorkspaceEdit) или команда, которую предложил LSP |
| **Ghost** | серый текст после курсора, не в буфере |
| **Completion** | список кандидатов (LSP или слова буфера) |
| **t9** | дополнение слова из слов текущего буфера |
| **Prose** | режим текста: обёртка, спеллчек, markdown-фичи |
| **Code** | режим кода: без обёртки, LSP, отступы |
| **LSP-сервер** | внешний процесс по filetype (gopls, ltex-ls, harper-ls…) |
| **Попап** | прямоугольник поверх текста ([[Примитив - Popup]]) |
| **Тост** | короткое уведомление ([[Экран - Уведомления]]) |
| **Сессия** | набор вкладок, позиций и недавних файлов, восстанавливается при старте |
| **State** | файл сессии (`~/.local/state/pero/state.toml`) |

## Правила языка

- Не говорим «панель» про вкладку и «таб» про popup.
- «Исправить» = quickfix по LSP; «заменить» = поиск и замена; это разные вещи.
- «Подсказка» в UI - это completion; «ghost» - серый текст; не смешивать.
- «Слово» - для t9/выделения; «токен» - только внутри LSP.
