## Запуск

```sh
cd ~/Projects/pero
go run .                 # пустой буфер
go run . ~/todo.md       # файл
go run . .               # папка = проект
go build -o pero .       # бинарник
go test ./...
```

Офлайн-сборка (если модули уже в кэше):

```sh
GOPROXY=file:///home/bongdo/go/pkg/mod/cache/download go build ./...
```

## Зависимости при запуске

- LSP-серверы — те же, что в micro `settings.json`: `gopls`, `ltex-ls`, `harper-ls`,
  `pyright-langserver`, `typescript-language-server`, `clangd`, `nimony-lsp`.
- Терминал с truecolor; zellij/niri поддерживают.
- Ничего не требует sudo и системных сервисов.
