# Решения

Список принятых и открытых решений. Формат: решение → почему → что это значит.

## Принято

| # | Решение | Почему |
|---|---|---|
| 1 | Имя - **pero** | нравится, короткое, не конфликтует с micro |
| 2 | Вкладки, **без сплитов** | сплиты - антипаттерн для workflow; micro-табы нравятся |
| 3 | Немодальный ввод | привычка micro, буквы всегда текст |
| 4 | Свой буфер (`[]rune`), не `bubbles/textarea` | нужны гаттер, подсветка, ghost, транзакции; textarea этого не даёт |
| 5 | Оверлеи - свой композитор поверх `[]string` | приём felix, попапы без патча рантайма |
| 6 | Ghost/completion - слои отрисовки, не буфер | иначе мусор в файле, undo и сохранении |
| 7 | Prose/Code - режимы по filetype | русский/markdown везде, где не код |
| 8 | Softwrap: prose вкл, код выкл; только конфиг | [[Softwrap]], `Alt-W` конфликтует с системой |
| 9 | AI - **без отдельной клавиши**; только ghost/completion | «внедрять только автокамплитом и дополнением предложений/блоков» |
| 10 | Копия felix-tui - локально, отдельной папкой | референс, не форк; правки - на riga |
| 11 | Документация - Obsidian-база (эта) | UX-примитивы первыми, архитектура потом |
| 12 | Подсветка - **chroma** | чистый Go, не JS; быстрее, чем писать правила самим |
| 13 | Спеллчек - **авто по содержимому**, один сервер | кириллица → ltex, иначе harper; второй не грузим |
| 14 | Новая вкладка - `Ctrl-O`, закрыть - `Alt-Q` | твоя привычка; вкладка = буфер = файл |
| 15 | `Ctrl-P` - открыть файл (в micro это поиск назад) | палитра важнее; см. [[Инвентарь клавиш micro]] |
| 16 | Softwrap без клавиши | `Alt-W` занят системой |
| 17 | Переход к строке не делаем | не нужен |
| 18 | Командная строка `Ctrl-E` - палитра команд | одна точка входа, действия без клавиш, один реестр для клавиш и меню |
| 19 | Клавиши вызывают команды из реестра | поведение не расходится между клавишей и палитрой |
| 20 | `Alt-a` - явный AI-запрос (по TODO M8) | автоматические подсказки остаются в ghost/completion; ADR #9 не отменяется |
| 21 | Темы - список с превью, выбор сохраняется в `config.toml` | 33 палитры, не нужно помнить имена и перезапускаться |
| 22 | Язык UI - `language = "en" \| "ru"`, по умолчанию EN | русский включается явно; неизвестное значение → English |
| 23 | Новая вкладка - `Ctrl-O` (вместо `Alt-O`) | привычный Ctrl-O; Alt-O можно вернуть в `[keys]` |
| 24 | Autopairs и обёртка выделения | `(` вокруг слова оборачивает, а не стирает; пары закрываются сами |
