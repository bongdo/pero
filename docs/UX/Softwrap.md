# Softwrap

## Что это

Длинная строка не влезает в ширину терминала. Есть два поведения:

- **Softwrap включён**: строка визуально переносится на следующую экранную строку. Файл
  не меняется, переносы - только на экране. Как в micro (`wordwrap: on`) и в браузере.
- **Softwrap выключен**: строка уходит за правый край, появляется горизонтальный скролл.
  Так работают IDE по умолчанию для кода.

## Решение по умолчанию

| Тип файла | Softwrap |
|---|---|
| markdown, txt, rst, org | включён |
| код (go, js, ts, rs, c, lua, nix, nim, py, sh) | выключен |
| конфиги (toml, json, yaml) | выключен |
| всё остальное | выключен |

Правило: **markdown/русский/английский - везде, где файл не код** (см. [[Prose и Code]]).
Переключается только в конфиге: `[editor] softwrap = "auto|on|off"` и переопределение по filetype. Клавиши для этого нет - `Alt-W` конфликтует с системой.

## Почему

- Проза: без переноса читать невозможно, горизонтальный скролл на каждой строке - боль.
- Код: перенос ломает структуру (отступы, длинные вызовы), и горизонтальное смещение
  помогает видеть уровень вложенности.

## Как это устроено

- Хранимый текст - логические строки. Рендер строит «экранные строки» из логических:
  `screen[i] = {logical, runeStart, runeEnd}`.
- Курсор: логическая позиция (line, rune) → экранная (row, col) через ту же карту.
  Клик мышью: экранная → логическая, обратное преобразование.
- Перенос - по словам (последний пробел в пределах ширины), иначе по рунам; отступ
  следующей экранной строки = отступ логической (для списков и кода).
- Номера строк в гаттере - только на первой экранной строке логической.

## Крайние случаи

- Слово длиннее ширины экрана - режем по рунам.
- Табы: сначала раскрываются в пробелы по `tabsize`, потом перенос.
- Курсор ровно на границе переноса - он в конце экранной строки, не в начале следующей.
- Выделение через перенос - подсвечиваются обе экранные строки.
- Ресайз терминала - карта пересчитывается, курсор остаётся на той же руне.
- Поиск: совпадение может пересекать перенос - подсветка всё равно целиком.
- Ghost-суффикс в конце перенесённой строки - рисуется на той экранной строке, где курсор,
  при нехватке места обрезается.

## Критерии готовности

- [ ] `softwrap` из конфига применяется: md переносится, go - нет.
- [ ] В markdown длинная строка переносится, в Go - нет.
- [ ] Клик мышью по перенесённой части ставит курсор в правильную руну.
- [ ] `Ctrl-Home/End`, `PgUp/PgDn` и `F8` работают в обоих режимах.
