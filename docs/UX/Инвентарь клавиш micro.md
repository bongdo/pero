# Инвентарь клавиш micro

Полный разбор дефолтных биндингов micro 2.0.15 (`internal/action/defaults_other.go`)
и твоих личных (`~/.config/micro/bindings.json`). Колонка «pero» - что делаем.

Обозначения: **keep** - как в micro, **remap** - действие остаётся, клавиша другая,
**drop** - не нужно, **new** - новое.

## Движение и выделение

| micro | Действие | pero | Комментарий |
|---|---|---|---|
| `↑↓←→` | курсор | keep | |
| `Shift-стрелки` | выделение | keep | |
| `Ctrl-←/→` | по словам | keep | UTF-8-слова |
| `Ctrl-Shift-←/→` | выделение по словам | keep | |
| `Home` / `End` | начало/конец строки (в micro - toggle) | remap | без toggle: обычные Home/End |
| `Shift-Home/End` | выделить до края | keep | |
| `Ctrl-Home/End` | начало/конец файла | keep | |
| `Ctrl-↑/↓` | начало/конец файла (в micro) | keep | нестандартно, но привычно |
| `Ctrl-Shift-↑/↓` | выделить до начала/конца файла | keep | |
| `PgUp/PgDn`, `Shift-PgUp/PgDn` | страница / с выделением | keep | |
| `Alt-←/→` | начало/конец текста с toggle | drop | toggle-позиция - лишнее, есть Home/End |
| `Alt-Shift-←/→` | выделить до края | drop | дубль Shift-Home/End |
| `Alt-{` / `Alt-}` | абзац назад/вперёд | keep | удобно в prose |

## Что micro умеет командами, но мы не биндим

- `replace`, `replaceall` - у нас `Ctrl-H`.
- `vsplit`, `hsplit`, `tab` - сплиты не нужны.
- `term` - терминал в редакторе не нужен (zellij).
- `plugin` - плагинов не будет в v1.
- `reload` - `Ctrl-Shift-R` позже, если понадобится.
- `goto` - не нужен.

## Итог

- Взято как есть: движение, выделение, правка, undo, поиск (Ctrl-F), LSP-альты, Esc-цепочка, колесо/драг.
- Переосмыслено: открытие (`Ctrl-P`), новая вкладка (`Ctrl-O`), закрытие (`Alt-Q`),
  вкладки (`Alt-J/K`), поиск-навигация (`F3`), замена (`Ctrl-H`), помощь (`F1`).
- Выброшено: сплиты, макросы, мультикурсор, command mode, shell mode, keymenu,
  overwrite, F4/F7/F10, Alt-W.
