# Примитив — Popup

Базовый прямоугольник поверх текста. На нём строятся [[Экран — Completion]],
[[Экран — Quickfix]], [[Экран — Открытие файла]], [[Экран — Помощь]].

## Анатомия

```
╭ Заголовок ──────────────────╮
│ содержимое: строки/список   │
│ ...                         │
╰ подсказки · счётчик ────────╯
```

- Рамка, заголовок слева (может быть пустым), футер с подсказками.
- Внутренняя ширина = max(ширина содержимого, 24), не шире экрана − 4.
- Высота = min(строк содержимого, 8..12) + 2 рамки + футер.
- Фон панели, текст — обычный; выбранная строка — фон выделения.

## Позиционирование

- Якорь: под курсором (completion/quickfix) или по центру (help).
- Если не помещается вниз — раскрывается вверх; если не помещается вправо — сдвиг влево.
- Никогда не выходит за границы экрана.
- В терминале меньше 40×10 попап не показывается (кроме help — он на весь экран).

## Поведение

- Одновременно открыт **только один** popup; новый закрывает старый.
- `Esc` закрывает; клик вне закрывает.
- Popup забирает клавиши до текста (см. [[Архитектура]] — порядок фокуса).
- Внутри: `↑↓`/`Ctrl-N/P` — навигация, `Enter` — действие, `PgUp/PgDn` — если строк много.
- Мышь: наведение меняет выбранную строку, клик выполняет, колесо прокручивает.
- Список длиннее окна — счётчик `3/12` в футере, без скроллбара.

## Отрисовка

- Рендерим экран в `[]string`, попап — прямоугольник, вставляемый в готовые строки с
  обрезкой по ANSI-ширине (приём из `felix-tui/internal/ui/dialog.go:567 overlayAt`).
- Не пересчитываем весь экран — только строки попапа.
- Тени/прозрачности нет: под попапом текст не виден (проще и читаемее).

## Крайние случаи

- Ресайз — пересчитать позицию, не оставлять обрезки.
- Изменился текст под попапом — попап не перерисовывается целиком, но позиция остаётся.
- Длинная строка списка — обрезается с `…`, полный текст — в подписи/тултипе.
- Unicode в содержимом — ширина по `uniseg`.

## Критерии готовности

- [ ] Попап у нижнего края раскрывается вверх.
- [ ] Esc/клик вне закрывают, фокус возвращается в текст.
- [ ] В 40 колонках попап не вылезает и не ломает рамку.
- [ ] Колесо и стрелки двигают выбор одинаково.
