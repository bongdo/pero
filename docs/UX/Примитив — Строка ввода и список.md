# Примитив — Строка ввода и список

Основа поиска, открытия файлов, меню и переименования. Один виджет, разные данные.

## Строка ввода

- Однострочная, с курсором, выделением, вставкой из буфера.
- `Home`/`End`, `Ctrl-A`, `Ctrl-U` (очистить), `Ctrl-W` (удалить слово).
- `Ctrl-V` — вставка; длинный текст не ломает строку, а прокручивается горизонтально.
- Placeholder — серым, исчезает при вводе.
- Не принимает переводы строк: `Enter` = подтвердить, не вставить.

## Список

- Строки фиксированной высоты, выбранная подсвечена.
- Фильтрация по вводу: подстрока без учёта регистра; подсветка совпадения.
- `↑↓` — движение, `PgUp/PgDn`, `Home/End` — к началу/концу.
- `Tab`/`Shift-Tab` — дополнить выбранным (в нашем случае — вставить в строку ввода).
- В футере: `N из M`, подсказки, при необходимости — `↑↓` вверх/вниз.

## Состояния

| Состояние | Поведение |
|---|---|
| Нет результатов | текст `ничего не найдено`, Enter не работает |
| Один результат | выбран сразу, Tab дополняет, Enter подтверждает |
| Много | прокрутка, выбранный не выходит за пределы видимой части |
| Загрузка | `…` в футере, список постепенно наполняется |
| Ошибка | красная строка под списком, не тост |

## Мышь

- Клик — выбрать и выполнить только по двойному клику/кнопке действия.
- Наведение — перемещает выбор (как в felix).
- Колесо — прокрутка без смены выбора.

## Крайние случаи

- Кириллица: фильтр по рунам, регистр через `strings.EqualFold`-логику.
- Вставка многострочного текста в строку ввода — схлопываем в одну строку (пробелы).
- Очень длинный список (100k) — рисуем только видимое, фильтрация не в UI-потоке.
- Ввод во время загрузки — фильтр применяется к уже пришедшим, остальные добавляются.

## Критерии готовности

- [ ] Ввод и Backspace не ломают позицию курсора.
- [ ] Русский фильтр работает.
- [ ] `Tab` дополняет, `Enter` подтверждает, `Esc` отменяет.
- [ ] Список на 100k строк не лагает при прокрутке.
