# Мышь

Мышью можно всё, что нужно в 90% времени. Остальное - клавиши. Паритет: каждое действие
мышью имеет клавишу (см. [[Карта клавиш]]).

## Текст

| Жест | Действие |
|---|---|
| Клик | поставить курсор |
| Двойной клик | выделить слово |
| Тройной клик | выделить строку |
| Drag | выделение, за границей окна - автоскролл |
| `Shift`+клик | выделить от якоря |
| Колесо | скролл 3 строки |
| `Ctrl`+колесо | (не используем - зум не нужен) |
| ПКМ | контекстное меню ([[Экран - Контекстное меню]]) |

### Планируется (M10)

| Жест | Действие |
|---|---|
| `Ctrl`+клик по переменной/функции | перейти к объявлению (LSP definition) |
| `Ctrl`+клик по `http(s)://…` | открыть ссылку в браузере |
| `Ctrl`+клик по `[[Note]]` / `[[Note#Heading]]` | открыть заметку/заголовок в Obsidian |
| `Ctrl`+клик по `# Заголовок` в vault | открыть текущую заметку на заголовке |

Подробности и открытые вопросы - [[M10 - ссылки и переходы]].

## Вкладки

| Жест | Действие |
|---|---|
| Клик | переключить |
| Средний клик | закрыть (с вопросом, если грязная) |
| ПКМ | меню вкладки |
| Колесо над полосой | прокрутить полосу при переполнении |

## Попапы и списки

| Жест | Действие |
|---|---|
| Наведение | переместить выбор |
| Клик | выполнить действие строки |
| Клик вне | закрыть |
| Колесо | прокрутить список |

## Ограничения и особенности

- В zellij координаты могут приходить со смещением - проверяем на живом zellij.
- В ssh-сессии мышь работает, но clipboard - только OSC52 ([[Решения]]).
- Курсор мыши не должен «залипать» на границе: после клика клавиатура продолжает оттуда.
- Drag за пределы окна: автоскролл с ускорением, без рывков.
- Правая кнопка не должна менять выделение, если клик внутри него.

## Критерии готовности

- [ ] Клик по любой руне (включая конец строки и перенесённую часть) ставит курсор туда.
- [ ] Drag + автоскролл выделяет ровно то, что подсвечено.
- [ ] Средний клик закрывает только выбранную вкладку.
- [ ] В zellij клик не смещён на строку/колонку.
