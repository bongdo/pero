# Экран — Completion (Ctrl-Space)

## Зачем

Дописать слово, имя функции, поле структуры. Для кода — из LSP, для текста — из слов
файла (t9). Это «явный» список; то же самое, но серым, — [[Экран — Ghost text]].

## Что видно

```
   12 │ func (m *model) update(▏
      ╭────────────────────────────────────╮
      │ › update        func  (m) error    │
      │   UpdateMsg     type               │
      │   updateView    func  () string    │
      ╰ 3 из 12 · ↑↓ · ↵ · Esc ────────────╯
```

- Popup под курсором, ширина по содержимому, максимум 8 строк.
- Слева маркер выбранного, справа — вид (func/type/word) и краткая подпись.
- Внизу — сколько всего и подсказки.

## Источники (по приоритету)

1. LSP-сервер, если он жив для этого filetype.
2. Слова из буфера (t9) — для prose и как fallback, если LSP молчит.
3. Ничего — попап не показывается, тост `нет подсказок` не нужен.

Дубликаты убираются: одно слово — одна строка, источник помечен.

## Поведение

| Действие | Клавиши | Мышь |
|---|---|---|
| Открыть | `Ctrl-Space` | — |
| Фильтровать | печать (список сужается) | — |
| Листать | `↑`/`↓`, `Ctrl-N/P`, `PgUp/PgDn` | колесо, наведение |
| Принять | `Tab` или `Enter` | клик |
| Закрыть | `Esc` | клик вне |
| Открыть снова | `Ctrl-Space` | — |

## Состояния

| Состояние | Поведение |
|---|---|
| 1 кандидат | сразу подставить, попап не показывать |
| 0 кандидатов | попап не открывается; ничего не вставляем |
| LSP думает | попап с `…`, старые кандидаты не пропадают |
| LSP не ответил за 1 с | показываем слова из буфера |
| Курсор в середине слова | фильтр по префиксу до курсора, вставка заменяет остаток слова |
| Read-only | `Ctrl-Space` игнорируется |

## Крайние случаи

- Popup у нижней границы экрана — раскрывается вверх.
- Длинные сигнатуры — обрезаем по ширине, полная подпись в ghost/`Alt-u`.
- Кириллица и эмодзи: ширина по `uniseg`.
- Устаревший ответ LSP (набрали ещё букву) — сверяем версию запроса и префикс, иначе
  вставим мусор.
- Принятие — одна транзакция undo, чтобы `Ctrl-Z` вернул слово целиком.

## Критерии готовности

- [ ] В Go: `Ctrl-Space` после `m.` показывает методы LSP, Tab вставляет.
- [ ] В markdown: `Ctrl-Space` дополняет слово из файла.
- [ ] Esc закрывает, ничего не вставив.
- [ ] Вставка откатывается одним `Ctrl-Z`.
