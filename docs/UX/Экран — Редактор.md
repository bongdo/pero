# Экран — Редактор

Главный и единственный постоянный экран. Всё остальное — оверлеи поверх него.

## Зачем

Человек открыл файл и пишет. Хочет: видеть текст, курсор, ошибки, позицию, вкладки и
ничего лишнего.

## Что видно

```
 Alt-J/K ─────────────────────────────────────────────────────────────
  todo.md ●   README.md   main.go
 ─────┬──────────────────────────────────────────────────────────────
   12 │ - [ ] разобраться с lsp в micro
   13 │ - [x] прочитать про react
   14 │ - [ ] довести tui до конца▏· подсказка ghost
 ─────┴──────────────────────────────────────────────────────────────
  todo.md  md  LF  14:38  2 ошибки 0 предупр.    F1 help   Ctrl-P open
```

| Зона | Что показывает | Мышью |
|---|---|---|
| Полоса вкладок | вкладки, `●` у грязных, активная подсвечена | клик — переключить, средний клик — закрыть |
| Гаттер | номера строк, маркер текущей | клик — ничего (v1) |
| Текст | строки, курсор, выделение, подчёркивания диагностик, ghost-суффикс | клик — курсор, drag — выделение, колесо — скролл |
| Статус-бар | файл, filetype, EOL, позиция, счётчик ошибок, подсказка | клик по счётчику ошибок — первая ошибка |

Полоса вкладок **скрыта, когда вкладка одна** — имя уже в статусе. Появляется со второй.

## Состояния

| Состояние | Как выглядит |
|---|---|
| Пустой буфер | `pero` без аргументов, подсказка `Ctrl-P — открыть файл, F1 — помощь` |
| Обычное | как на схеме выше |
| Грязный буфер | `●` после имени вкладки и в статусе |
| Ошибки LSP | подчёркивание диапазона + счётчик в статусе, `F8` — переход |
| Идёт LSP | в статусе `LSP…`, ввод не блокируется |
| LSP упал | `LSP off` в статусе, текст редактируется |
| Файл изменён извне | тост + выбор «перезагрузить / оставить моё» |
| Read-only (бинарник, >10 МБ, /nix/store) | в статусе `read-only`, ввод не меняет буфер |
| Нет прав/файл удалён | ошибка в статусе, буфер остаётся |

## Кнопки и клавиши

Полный список — [[Карта клавиш]]. Минимум для этого экрана: печать, стрелки, `Ctrl-S`,
`Ctrl-Q`, `Ctrl-P`, `Ctrl-F`, `F1`, `Alt-J/K`, `Esc`.

## Крайние случаи

- Терминал 40×10: гаттер скрывается, статус ужимается до `файл · поз · ошибки`.
- Очень длинная строка: см. [[Softwrap]] — в prose переносится, в коде горизонтальный скролл.
- Курсор в конце строки: ghost рисуется после курсора, не сдвигая текст.
- Выделение мышью за границей окна: автоскролл.
- Кириллица/эмодзи: позиция и ширина считаются по рунам и `uniseg` (см. [[Примитив — Курсор и выделение]]).
- 20+ вкладок: полоса скроллится, активная всегда видна ([[Экран — Вкладки]]).

## Критерии готовности

- [ ] Открыл файл, поставил курсор мышью в любое место (включая конец строки) — курсор там.
- [ ] Набрал русский текст с «ё», эмодзи — курсор не уехал.
- [ ] `Ctrl-S` сохраняет байт-в-байт с исходным EOL.
- [ ] Ошибка LSP видна подчёркиванием и в счётчике, `F8` доводит до неё.
- [ ] В терминале 40 колонок ничего не разъезжается и не паникует.
- [ ] Ghost появляется и исчезает, не оставляя следов в буфере и undo.
