# Экран - Ghost text

## Зачем

Подсказка должна быть видна, пока пишешь, но не мешать и не попадать в файл. Серый
суффикс после курсора - самый дешёвый способ: не двигает текст, не ломает undo, исчезает
от любой клавиши.

## Что видно

```
  14 │ - [ ] довести tui до конца▏до конца
                                  └ серым, не в буфере
```

- Серый (dim) текст сразу после курсора, без рамки и фона.
- Максимум - остаток текущей строки; многострочные блоки - позже.
- В статусе ничего не меняется; принятие - `Tab`.

## Откуда берётся

1. Первый кандидат [[Экран - Completion]] (LSP), если курсор в конце слова/строки.
2. Для prose - следующее слово из слов буфера (t9), если LSP нет.
3. Позже - AI-дополнение предложения/блока, отдельным источником (см. [[Решения]]).

Источники не смешиваются: показываем один, с приоритетом LSP.

## Поведение

| Действие | Клавиши |
|---|---|
| Показать | само, через 250 мс после последней правки |
| Принять | `Tab` |
| Погасить | `Esc` |
| Игнорировать | любая другая клавиша - ghost исчезает, ввод продолжается |
| Выключить | `ghost = false` в конфиге ([[Экран - Настройки]]) |

## Правила

- Ghost **никогда** не попадает в буфер, undo или файл. Это слой отрисовки.
- Показывается только когда курсор в конце слова или строки; в середине слова - не
  показываем (там работает обычный completion).
- Не показывается при выделении, в read-only, во время IME-композиции.
- Не показывается, если кандидат короче 2 символов или совпадает с уже набранным.
- Если после показа пользователь напечатал символ - кандидат проверяется на префикс;
  не совпал - просто исчезает, без «дописывания».

## Состояния

| Состояние | Поведение |
|---|---|
| LSP молчит | prose → слова из буфера; код → ничего |
| Пустой файл | ничего |
| Курсор в конце строки | ghost переносится/обрезается по ширине ([[Softwrap]]) |
| Выделение | ghost скрыт |
| Печать | ghost скрыт, пока не пройдёт 250 мс |

## Крайние случаи

- Смена вкладки - ghost старой вкладки не должен протечь в новую.
- Ресайз - пересчитать позицию, не оставлять обрезки.
- `Tab` при открытом completion-popup принимает popup, а не ghost (popup приоритетнее).
- Ghost и подсветка диагностики на одном месте - ghost рисуется после текста, подчёркивание
  остаётся под текстом.
- Медленный LSP: ghost не блокирует ввод; пришёл позже - показать, если префикс всё ещё совпадает.

## Критерии готовности

- [ ] В markdown после слова через 250 мс виден серый вариант, `Tab` дописывает.
- [ ] `Esc` гасит, в файле и undo ничего нет.
- [ ] Печать после ghost не оставляет «хвостов».
- [ ] Переключение вкладок не показывает ghost из другой.
- [ ] `ghost = false` полностью выключает.
