# Экран - Уведомления (тосты)

## Зачем

Сообщить о результате, не забирая фокус и не перекрывая текст. «Сохранено», «исправлено»,
«LSP запускается», «файл изменён на диске».

## Что видно

```
                                                   ╭──────────────────╮
                                                   │ ✓ сохранено      │
                                                   ╰──────────────────╯
```

- Правый нижний угол, над статус-баром.
- Иконка/цвет по типу: `✓` success, `!` warning, `×` error, `…` progress.
- Одна строка, ширина ≤ 40 колонок, длинный текст обрезается.

## Поведение

| Тип | Живёт | Закрывается |
|---|---|---|
| success | 2 с | сам, клик |
| info | 3 с | сам, клик |
| warning | 5 с | сам, клик |
| error | до действия | `Esc`, клик |
| progress | до завершения | - |

## Правила

- Тосты не копятся: новый вытесняет старый, важные (error) - нет.
- Тосты не перекрывают курсор и строку, где курсор.
- Один тост на событие, без дублей (`сохранено` не показывается дважды).
- Ошибка должна содержать действие или причину: `нет прав на запись`, а не `ошибка`.

## Крайние случаи

- Терминал 40×10: тост не шире экрана минус 2, статус-бар не перекрывает.
- Много ошибок LSP: не тост на каждую, только счётчик в статусе.
- Файл изменён извне - это не тост, а вопрос с выбором (см. [[Экран - Редактор]]).

## Критерии готовности

- [ ] `Ctrl-S` → тост `сохранено`, исчезает сам.
- [ ] Ошибка сохранения висит, пока не нажмёшь Esc.
- [ ] Тосты не мешают печатать и не перекрывают курсор.
