# Экран — Вкладки

## Зачем

Несколько файлов одновременно, без сплитов. Вернуться к тому, что открывал вчера.

## Что видно

```
  todo.md ●   README.md   internal/ui/model.go   ⌄ 3 скрыто
  ────────────────────────────────────────────────────────
```

- Имя файла (не полный путь; полный — в статусе и в тултипе, если влезет).
- `●` — есть несохранённые изменения.
- Активная вкладка — фон/цвет, не только жирный.
- Длинные имена обрезаются по центру: `internal/ui/mod…el.go`.
- Когда вкладок больше ширины — стрелки `‹ ›` и счётчик скрытых.

## Поведение

| Действие | Клавиши | Мышь |
|---|---|---|
| Следующая/предыдущая | `Alt-J` / `Alt-K` | клик по вкладке |
| По кругу | `Ctrl-Tab` / `Ctrl-Shift-Tab` | — |
| Закрыть | `Alt-Q` | средний клик, `×` на активной |
| Новая (с выбором файла) | `Ctrl-O` | — |
| Открыть файл | `Ctrl-P` | — |
| Закрыть остальные | из контекстного меню вкладки | ПКМ по вкладке |

## Состояния

| Состояние | Поведение |
|---|---|
| Одна вкладка | полоса скрыта, имя в статусе |
| Грязная | `●`, `Alt-Q` спрашивает «сохранить / не сохранять / отмена» |
| Файл уже открыт | переход на существующую вкладку, не дубль |
| Файл удалён с диска | вкладка остаётся, в статусе `deleted`, при сохранении — создать заново или save as |
| 20+ вкладок | горизонтальный скролл, активная всегда видна |
| Восстановление сессии | при старте открываются вкладки и позиции курсоров из state-файла |

## Крайние случаи

- Одинаковые имена из разных папок (`README.md` в двух проектах) — показываем минимально
  различающийся путь: `pero/README.md`, `felix-tui/README.md`.
- Закрытие окна с грязными вкладками: один общий вопрос «сохранить всё / выйти без / отмена».
- Восстановление сессии не должно открывать файлы, которых больше нет, — молча пропускаем и
  пишем в статус `пропущено: N`.
- Вкладка открыта, файл изменили извне — см. [[Экран — Редактор]] (не перетирать).

## Критерии готовности

- [ ] 25 вкладок: активная видна, стрелки работают, ничего не наезжает.
- [ ] Грязная вкладка не закрывается без вопроса.
- [ ] Перезапуск восстанавливает вкладки и позиции.
- [ ] Дубль файла не создаётся.
