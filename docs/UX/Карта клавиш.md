# Карта клавиш

Принципы: буквы всегда вводят текст; действия - `Ctrl-*`, `Alt-*`, `F-*`; `Esc` - отмена;
`Ctrl-Q` - выход. Полный разбор, что взято из micro и что выброшено - [[Инвентарь клавиш micro]].

## Файлы и вкладки

| Клавиши | Действие |
|---|---|
| `Ctrl-O` | новая вкладка + выбор файла (пустой буфер под ней) |
| `Ctrl-P` | открыть файл (в пустой вкладке - там же, иначе в новой) |
| `Ctrl-E` | командная строка (все команды) |
| `Ctrl-S` | сохранить |
| `Ctrl-Shift-S` | сохранить как |
| `Alt-Q` | закрыть вкладку (спросить, если грязная) |
| `Alt-J` / `Alt-K` | следующая / предыдущая вкладка |
| `Ctrl-Tab` / `Shift-Ctrl-Tab` | по кругу |
| `Ctrl-Q` | выйти (спросить про грязные) |

## Правка

| Клавиши | Действие |
|---|---|
| `Ctrl-Z` / `Ctrl-Y` | undo / redo |
| `Ctrl-A` | выделить всё |
| `Ctrl-C` / `Ctrl-X` / `Ctrl-V` | копировать / вырезать / вставить |
| `Ctrl-K` | вырезать строку |
| `Ctrl-D` | дублировать строку |
| `Alt-Backspace` | удалить слово слева |
| `Tab` | принять completion/ghost, иначе отступ |
| `Shift-Tab` | снять отступ |
| `Ctrl-Space` | completion ([[Экран - Completion]]) |
| `Esc` | закрыть оверлей → снять выделение → погасить ghost |
| `Alt-t` | markdown-чекбокс ([[Примитив - Markdown-чекбокс и списки]]) |
| `Alt-s` | схлопнуть повторные пробелы |

## Поиск

| Клавиши | Действие |
|---|---|
| `Ctrl-F` | найти |
| `Ctrl-H` | заменить |
| `F3` / `Shift-F3` | следующее / предыдущее совпадение |
| `Enter` / `Shift-Enter` (в поиске) | следующее / предыдущее |
| `Esc` | закрыть поиск |

## Осознанно не биндим

- `Alt-W` - softwrap только в конфиге: клавиша конфликтует с системой.
- `Ctrl-G`, `Ctrl-L` - переход к строке не нужен.
- Сплиты, терминал, макросы, мультикурсор, shell mode, keymenu.
- AI-клавиша: `Alt-a` - явный вызов; автоматические подсказки только через ghost/completion ([[Решения]]).
