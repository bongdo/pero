# Экран — Quickfix (Alt-.)

## Зачем

Подчёркнута ошибка. Хочется исправить, не читая правило и не набирая руками. Один
`Alt-.` — и выбрал фикс.

## Что видно

```
   13 │ - [ ] довети tui до конца
      │       ▔▔▔▔▔▔
      ╭ Исправить ──────────────────────────────────────╮
      │ 'довети': возможно, орфографическая ошибка      │
      │ ─────────────────────────────────────────────── │
      │ › 1  Use 'Довести'                              │
      │   2  Use 'Довезти'                              │
      │   3  Use 'Давите'                               │
      │   4  Hide false positive                        │
      ╰ 1–4 выбрать · ↵ применить · Esc ────────────────╯
```

- Заголовок — текст диагностики, под курсором.
- Список действий; номер = цифра на клавиатуре.
- Отдельно помечается «спрятать ложное срабатывание», если сервер такое умеет.

## Поведение

| Действие | Клавиши | Мышь |
|---|---|---|
| Открыть | `Alt-.` | ПКМ → «Исправить» |
| Выбрать | `↑`/`↓` или цифра `1–9` | наведение, клик |
| Применить | `Enter` | клик |
| Закрыть | `Esc` | клик вне |
| Отменить правку | `Ctrl-Z` | — |

## Что происходит при выборе

1. Правка применяется как **одна транзакция** (undo целиком).
2. Курсор остаётся там, где был, либо переходит на место правки, если правка была в другом
   месте файла (показать тост `исправлено в строке N`).
3. Тост: `исправлено: Use 'Довести'`.
4. Если сервер вернул не правку, а команду — выполняем её, ждём `workspace/applyEdit`,
   правки всё равно проводим транзакцией.

## Состояния

| Состояние | Поведение |
|---|---|
| Один фикс | применяется сразу, без меню |
| Нет фиксов на строке | тост `нет фиксов`, курсор не двигается |
| Нет LSP | тост `LSP не запущен для md` |
| Сервер думает | `…` в заголовке, `Esc` отменяет ожидание |
| Ошибка применения | тост с текстом, буфер не меняется |
| Несколько диагностик на строке | в заголовке первая, действия всех диагностик строки |

## Крайние случаи

- Фикс в другом файле — открываем вкладку, применяем, показываем тост.
- Фикс пересекает перенос строки — применяем по позициям рун, не по экранным строкам.
- Правка ломает другую (пересекающиеся диапазоны) — применяем с конца файла.
- LSP вернул `null` — то же, что «нет фиксов».
- Ошибка в файле, который изменился на диске — сначала спрашиваем про перезагрузку.

## Критерии готовности

- [ ] `Alt-.` на ltex-ошибке показывает варианты и вставляет «Довести».
- [ ] `Ctrl-Z` откатывает фикс целиком.
- [ ] Пустая строка → `нет фиксов`, ничего не меняется.
- [ ] Правка в другом файле открывает его и не теряет курсор.
