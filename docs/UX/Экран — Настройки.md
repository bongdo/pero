# Экран — Настройки

## Зачем

Поменять тему, поведение под файл, биндинги. Без пересборки и без «плагинов».

## Что видно

Настроек как экрана **нет** — это файл и один тост при ошибке:

- `~/.config/pero/config.toml` — настройки.
- `~/.local/state/pero/state.toml` — сессия (вкладки, позиции, недавние).
- Ошибка в конфиге → тост `config: строка 12: неизвестный ключ`, редактор стартует
  с дефолтами.

## Черновик конфига

```toml
theme = "everforest"   # 33 темы: everforest, vesper, nord, plain,
                       # catppuccin-*, gruvbox-*, tokyonight-*, dracula,
                       # solarized-*, one-*, monokai, ayu-*, kanagawa-*,
                       # rose-pine-*, github-*, zenburn, flexoki-dark
language = "en"        # en | ru; пусто/неизвестно → en

[editor]
tabsize = 4
tabstospaces = true
softwrap = "auto"      # auto | on | off, auto = по filetype
ghost = true
ghost_delay_ms = 250
scrollmargin = 3
restore_session = true
autopairs = true       # пары () [] {} "" '' ``
trim_trailing_whitespace = false
final_newline = true

[markdown]
checkbox = true        # Alt-t
continue_list = true
spell = "auto"         # auto | ltex | harper | off

[lsp]
servers = { go = "gopls", markdown = "ltex-ls", python = "pyright-langserver --stdio" }

[ignore]
dirs = [".git", ".jj", "node_modules", "target", ".direnv", "result"]

[keys]
"Alt-t" = "markdown.checkbox"
"Alt-." = "lsp.codeaction"
```

## Поведение

| Действие | Когда |
|---|---|
| Прочитать конфиг | при старте |
| Перечитать | `Ctrl-Shift-R` (если сделаем), иначе перезапуск |
| Ошибка | тост, работаем на дефолтах |
| Неизвестный ключ | предупреждение, не падать |

## Крайние случаи

- Конфига нет — создаём дефолтный при первом запуске (как felix).
- Биндинг конфликтует со встроенным — предупреждение, встроенный не перетирается молча.
- Файл конфига битый (не TOML) — тост, дефолты.
- Тема не найдена — `plain` + тост.

## Критерии готовности

- [ ] Правка темы в конфиге видна после перезапуска.
- [ ] Ошибка в TOML не роняет редактор.
- [ ] `state.toml` восстанавливает вкладки, даже если конфиг сломан.
