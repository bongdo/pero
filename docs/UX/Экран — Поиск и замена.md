# Экран — Поиск и замена

## Зачем

Найти слово в файле, перейти к нему, заменить — без ухода в другой режим и без запоминания
команд. Частый сценарий — поправить опечатку по всему markdown.

## Что видно

Поиск (`Ctrl-F`) — строка над статус-баром:

```
  todo.md  md  LF  14:38                             2 ошибки
  Найти: micro▏               3 из 7   ↵ далее   ⇧↵ назад   Esc
```

Замена (`Ctrl-H`) — две строки:

```
  Найти:     micro▏                    3 из 7
  Заменить:  editor▏     ↵ заменить   Ctrl-A заменить все   Esc
```

- Все видимые совпадения подсвечены; текущее — другим цветом.
- Счётчик `3 из 7` обновляется на лету.
- При вводе файл не меняется.

## Поведение

| Действие | Клавиши | Мышь |
|---|---|---|
| Открыть поиск | `Ctrl-F` | — |
| Открыть замену | `Ctrl-H` | — |
| Следующее/предыдущее | `Enter` / `Shift-Enter` | клик по счётчику — далее |
| Перейти к совпадению | — | клик по подсветке |
| Заменить одно | `Enter` в поле замены | — |
| Заменить все | `Ctrl-A` | — |
| Закрыть | `Esc` | клик по `Esc` в подсказке |
| Вставить слово под курсором | `Ctrl-F` с выделением — ищет выделенное | — |

## Состояния

| Состояние | Поведение |
|---|---|
| Ничего не найдено | `0 из 0`, строка поиска краснеет |
| Поиск с выделением | подставляет выделенный текст в запрос |
| Замена без совпадений | кнопки неактивны |
| Файл огромный | подсвечиваем только видимое, общее число считаем в фоне |
| Read-only | замена недоступна, кнопки серые |

## Крайние случаи

- Кириллица: регистронезависимый поиск, «ё» = «е» — опция в конфиге, по умолчанию **нет**
  (иначе поиск врёт).
- Совпадение пересекает перенос строки в softwrap — подсвечиваем целиком ([[Softwrap]]).
- Замена не должна портить EOL и отступы.
- После замены всех: счётчик, undo одной транзакцией (`Ctrl-Z` откатывает всё).
- Поиск не должен менять позицию курсора, пока не нажали Enter.
- Regex — не в v1; задел: галочка `.*` в строке поиска.

## Критерии готовности

- [ ] `Ctrl-F`, ввод — подсветка на месте, Enter ходит по кругу.
- [ ] `Ctrl-H` заменяет одно и все, `Ctrl-Z` откатывает всё.
- [ ] Русский текст ищется.
- [ ] На 100k-строчном файле ввод не лагает.
