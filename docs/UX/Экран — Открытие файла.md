# Экран — Открытие файла (Ctrl-P / Ctrl-O)

## Зачем

Открыть файл из проекта, не выходя из редактора и не вспоминая путь. Это главный способ
навигации, поэтому он же — «палитра».

## Модель

- Вкладка = буфер = файл ([[Слои интерфейса]]).
- Любое открытие файла происходит **во вкладке**, а не «вместо» неё:
  - текущая вкладка пустая (безымянная) — файл открывается в ней;
  - в текущей уже есть файл — открывается новая вкладка, чтобы не потерять буфер.
- `Ctrl-O` сначала создаёт пустую вкладку и показывает в ней палитру:
  `Esc` — остаётся безымянный буфер, можно писать; `Enter` — файл открывается в этой вкладке.
- `Ctrl-P` в пустой вкладке ведёт себя так же, но не создаёт новую, если текущая пустая.
- Файл, который уже открыт, — переключаемся на его вкладку, второй не создаём.
- Буфер никогда не заменяется молча: либо он пустой, либо открывается новая вкладка.

## Что видно

```
╭ Открыть ─────────────────────────────────────────────╮
│ > mod                                              ▏ │
│ ──────────────────────────────────────────────────── │
│ › internal/ui/model.go                    ui · 1409  │
│   internal/ui/mouse.go                    ui ·  407  │
│   README.md                               — ·  9.6K  │
│   ...                                                │
╰ 13 из 214 · ↑↓ выбрать · ↵ открыть · Esc закрыть ────╯
```

- Строка ввода с фильтром.
- Список: путь относительно корня проекта, справа — файлtype или размер, дата.
- Снизу — количество совпадений и подсказки.

## Откуда берутся файлы

1. **Корень проекта** — папка, из которой запущен `pero`, или git/jj-корень.
2. **Недавние** — из state-файла, открытые ранее (сейчас в других вкладках).
3. **Файлы рядом** — если проект не определён, текущая директория.

Игнор по умолчанию: `.git`, `.jj`, `node_modules`, `target`, `.direnv`, `result*`,
`dist`, `build`, `.cache`. Настраивается в конфиге.

## Поведение

| Действие | Клавиши | Мышь |
|---|---|---|
| Ввод фильтра | печать | — |
| Листать | `↑`/`↓`, `Ctrl-N/P` | колесо, клик |
| Открыть | `Enter` | двойной клик |
| Закрыть | `Esc` | клик вне окна |
| Создать файл | `Ctrl-N` (если такого пути нет) | — |
| Открыть папку/путь | `~`, `/`, `./` — показать совпадения путей | — |
| Новая пустая вкладка + палитра | `Ctrl-O` | — |

## Состояния

| Состояние | Поведение |
|---|---|
| Пустой фильтр | недавние + первые 100 файлов проекта |
| Ничего не найдено | `нет файлов` + подсказка `Ctrl-N — создать` |
| Путь с `/` | показываем папки и файлы по этому пути |
| Очень большой проект | обход асинхронно, первые результаты сразу, счётчик растёт |
| Файл бинарный/большой | открывается, но read-only (см. [[Экран — Редактор]]) |

## Крайние случаи

- Симлинки: показываем как файл, открываем цель; циклы не обходим.
- Права: файл без прав на чтение — в списке есть, при открытии ошибка в статусе.
- Кириллица в именах: фильтр ищет без учёта регистра и по рунам.
- Проект на 100k файлов: обход ограничен по времени, остальное — по фильтру.
- `Ctrl-P` внутри попапа — переключение фокуса не закрывает его (ввод в поле).

## Критерии готовности

- [ ] `Ctrl-P`, три буквы, Enter — файл открыт, фокус в тексте.
- [ ] `Ctrl-O` + `Esc` — новая пустая вкладка, можно сразу писать.
- [ ] Открытие уже открытого файла переключает вкладку, а не дублирует.
- [ ] Кириллица и `ё` ищутся.
- [ ] `Ctrl-N` создаёт файл из введённого пути.
- [ ] На большом проекте popup появляется мгновенно.
