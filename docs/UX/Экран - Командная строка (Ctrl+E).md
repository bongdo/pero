# Экран - Командная строка (Ctrl-E)

## Зачем

Одна точка входа ко всем действиям редактора: как command bar в VS Code и как `>` в micro,
только с поиском и подсказками. Решает три задачи:

1. **Обнаружимость** - не надо помнить клавишу, можно найти команду по имени.
2. **Действия без клавиш** - softwrap, ghost, тема: клавиш нет, а команда есть.
3. **Один реестр** - каждая клавиша вызывает команду из этого же списка, поведение не
   расходится (см. [[Архитектура]]).

## Что видно

```
  12 │ - [ ] разобраться с lsp
  13 │ - [x] прочитать про react
  ▸ Сохранить файл                                   Ctrl-S
    Открыть файл по пути                             Ctrl-P
    Новый пустой буфер
    Показать все клавиши                             F1
    Выйти из редактора                               Ctrl-Q
  > save▏
```

- Строка ввода внизу, список над ней (до 8 строк), выбранная - подсветкой.
- Слева - название, справа - клавиша, если есть.
- Ввод фильтрует: подстрока или подпоследовательность, префикс важнее.
- Под списком ничего лишнего: счётчик не нужен, видно и так.

## Режимы строки

| Режим | Открывается | Что вводится |
|---|---|---|
| Команды | `Ctrl-E` | имя команды, фильтр |
| Путь | команда «Открыть файл по пути» или `Ctrl-P` | путь к файлу, `~` раскрывается |
| Аргумент | позже | `тема everforest`, `отступ 2` - вторая часть после пробела |

Переключение режима не создаёт второй оверлей: та же строка меняет подсказку и поведение
Enter. Это дешевле и не плодит состояния.

## Поведение

| Действие | Клавиши | Мышь |
|---|---|---|
| Открыть/закрыть | `Ctrl-E` | - |
| Фильтр | печать | - |
| Листать | `↑`/`↓`, `Ctrl-N/P` | колесо, наведение |
| Дополнить | `Tab` | - |
| Выполнить | `Enter` | клик по строке |
| Очистить ввод | `Ctrl-U` | - |
| Закрыть | `Esc` | клик вне |

## Как взаимодействует с остальным

| С чем | Правило |
|---|---|
| `Ctrl-P` | отдельная клавиша открывает ту же строку в режиме пути; команда `file.open` делает то же |
| Completion / quickfix | отдельные оверлеи; команда открывает их, только если есть LSP и кандидаты; иначе тост |
| Поиск | `Ctrl-F` открывает свою строку внизу; из командной строки - команда `edit.find` |
| Помощь | `F1` - полноэкранный оверлей; команда `help.keys` делает то же |
| Вкладки | `Ctrl-O`/`Alt-Q`/`Alt-J/K` - команды `tab.*`; из строки доступны по имени |
| Грязный буфер | `app.quit` спрашивает так же, как `Ctrl-Q`; `file.open` не затирает грязный буфер |
| Настройки | всё, что в конфиге, но нужен тумблер на лету - команда (`view.wrap`, `view.ghost`), а не клавиша |
| LSP | `lsp.*` видны, только если сервер запущен; иначе не показываются |

Правила приоритета:

- Открыт только один оверлей: командная строка закрывает completion/quickfix/поиск и наоборот.
- `Esc` закрывает строку, а не редактор.
- Пока строка открыта, буквы идут в неё, не в текст.
- Команда, которой нет условий (нет LSP), не показывается, а не «серая».

## Крайние случаи

- Ничего не найдено - «ничего не найдено», Enter ничего не делает, Esc закрывает.
- Кириллица в запросе - фильтр по названию, регистр не важен.
- Длинное название - обрезается, клавиша справа остаётся.
- Терминал 40 колонок - только название, клавиша скрывается; список до 3 строк.
- Очень длинный путь - строка прокручивается по горизонтали, курсор виден.
- Выполнение команды, меняющей состояние (сохранить/выйти), закрывает строку до выполнения.
- Ошибка команды - тост, строка уже закрыта.

## История

- Пустой запрос: последние выполненные команды сверху, затем все по порядку каталога.
- Хранится в state-файле, максимум 10.
- В v1 можно без истории; задел - поле `recent` в state.

## Почему не отдельный режим как в micro

В micro `Ctrl-E` открывает `>` и там живут команды с аргументами (`replace`, `goto`).
У нас строка - это **палитра с поиском**: список видно, фильтр на лету, клавиши-подсказки.
Аргументы появятся как второй режим той же строки, когда будет `theme`/`goto`.

## Критерии готовности

- [ ] `Ctrl-E` открывает, `Esc` закрывает, `Enter` выполняет.
- [ ] Фильтр работает на русском и английском, подпоследовательность тоже.
- [ ] `Ctrl-E` → «сохр» → Enter сохраняет файл.
- [ ] `Ctrl-P` открывает режим пути в той же строке.
- [ ] Ни одна команда не существует только в клавише: всё есть в каталоге.
