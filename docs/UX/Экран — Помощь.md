# Экран — Помощь (F1)

## Зачем

Не помнить все клавиши. Один экран со всем, что умеет редактор, и путями к конфигу.

## Что видно

```
╭ Помощь ───────────────────────────────────────────────╮
│ Файлы                                                 │
│   Ctrl-P    открыть файл            Ctrl-S  сохранить │
│   Ctrl-S    сохранить              Alt-Q   закрыть вкладку
│   Ctrl-P    открыть файл            Ctrl-Q  выйти     │
│                                                       │
│ Правка                    LSP                          │
│   Ctrl-Z/Y  undo/redo       Alt-u  hover               │
│   Ctrl-F/H  поиск/замена    Alt-d  определение         │
│   Alt-t     чекбокс         Alt-.  исправить           │
│                                                       │
│ Версия 0.1 · конфиг ~/.config/pero/config.toml        │
╰ Esc закрыть · ↑↓ прокрутка ───────────────────────────╯
```

- Секции по смыслу, а не «всё подряд».
- Прокрутка колесом/`↑↓`, `Esc` закрывает.

## Поведение

| Действие | Клавиши | Мышь |
|---|---|---|
| Открыть | `F1` | — |
| Закрыть | `Esc`, `F1` | клик вне |
| Прокрутка | `↑↓`, `PgUp/PgDn`, `g/G` | колесо |

## Правила

- Помощь берётся из карты клавиш, а не хардкодится вторым списком ([[Карта клавиш]]).
- Помощь показывает только реально зарегистрированные действия.
- Версия и путь конфига — внизу.

## Критерии готовности

- [ ] Каждая клавиша из карты видна в помощи.
- [ ] Помощь не мешает: `Esc` сразу возвращает в текст.
- [ ] На 40 колонках текст переносится, а не обрезается.
