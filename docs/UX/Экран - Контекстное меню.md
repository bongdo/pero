# Экран - Контекстное меню (ПКМ)

## Зачем

Мышью делать частые действия без клавиш. Меню контекстное: в тексте - про текст, во
вкладке - про вкладку. Никаких «настроек» в меню.

## Что видно

```
      ╭──────────────────────────╮
      │ Вырезать         Ctrl-X  │
      │ Копировать       Ctrl-C  │
      │ Вставить         Ctrl-V  │
      │ ──────────────────────── │
      │ Выделить всё     Ctrl-A  │
      │ Исправить…       Alt-.   │
      ╰──────────────────────────╯
```

Пункты с неактивным состоянием серые (нечего копировать, нет фиксов).

## Где открывается

| Зона | Пункты |
|---|---|
| Текст | Вырезать, Копировать, Вставить, Выделить всё, Исправить…, Найти слово |
| Вкладка | Сохранить, Закрыть, Закрыть остальные, Показать полный путь |
| Счётчик ошибок | Следующая ошибка, Список ошибок (в v1 - просто переход к первой) |

## Поведение

| Действие | Клавиши | Мышь |
|---|---|---|
| Открыть | - | ПКМ |
| Перемещение | `↑`/`↓` | наведение |
| Выбрать | `Enter` | клик |
| Закрыть | `Esc` | клик вне меню |
| Быстрое действие | `Ctrl-X/C/V/A` работает и без меню | - |

## Правила

- Правый клик **не** перемещает курсор, если он уже внутри выделения; иначе ставит курсор
  в точку клика (как в большинстве редакторов).
- Меню не перекрывает курсор, если есть место.
- Разрушающих действий без подтверждения нет (удаление файла - не в v1).
- Меню закрывается при скролле, ресайзе, смене вкладки.

## Крайние случаи

- Меню у правого/нижнего края - сдвигается внутрь экрана.
- Терминал 40 колонок - сокращённые подписи (`Вырезать` → `Вырез.`), горячие клавиши скрыты.
- Read-only - «Вырезать»/«Вставить» серые.
- Меню и попап completion одновременно невозможны: открытие одного закрывает другое.

## Критерии готовности

- [ ] ПКМ в тексте и во вкладке даёт разные меню.
- [ ] Клик вне закрывает, ничего не выполнив.
- [ ] Пункты с недоступным действием серые и не нажимаются.
- [ ] Мышь и клавиатура дают одинаковый результат.
