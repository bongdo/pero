# Примитив — Курсор и выделение

## Курсор

- Один курсор. Мультикурсор — не в v1.
- Позиция: `(логическая строка, индекс руны)`, не байт и не колонка экрана.
- Форма: блок в тексте, не мигает (мигание — настройка, по умолчанию выкл, чтобы не
  раздражать в терминале).
- Курсор может стоять после последней руны строки — это позиция «конец строки».
- На пустом буфере — строка 0, руна 0.

Правила перемещения:

| Клавиши | Куда |
|---|---|
| `←`/`→` | руна |
| `Ctrl-←`/`Ctrl-→` | слово (по пробелам/пунктуации UTF-8) |
| `Home`/`End` | начало/конец строки |
| `↑`/`↓` | та же экранная колонка, ближайшая возможная (перенос не ломает) |
| `PgUp`/`PgDn` | на высоту окна |
| `Ctrl-Home`/`Ctrl-End` | начало/конец файла |

## Выделение

- Якорь + курсор. Направление не важно, но запоминается для `Shift`-расширения.
- `Shift` + любое движение — расширяет; повторное движение без `Shift` — сбрасывает.
- Двойной клик — слово, тройной — строка (включая перевод строки).
- `Shift`-клик — от якоря до клика.
- Drag: якорь в точке нажатия, курсор следует за мышью; за границей окна — автоскролл.
- `Ctrl-A` — всё, `Esc` — снять выделение (первым делом, до закрытия оверлеев).

## Unicode и экран

- Кириллица — 1 колонка, CJK/эмодзи — 2, комбинирующие — 0.
- Ширина считается по `uniseg`/`go-runewidth`, а не по `len([]rune)`.
- Табы: при отрисовке раскрываются в `tabsize` пробелов; курсор ходит по руне таба, а
  экранная колонка считается после раскрытия.
- Перенос строки в softwrap: курсор помнит логическую позицию, экранная вычисляется
  ([[Softwrap]]).

## Крайние случаи

- Пустая строка: курсор в позиции 0, `Home`/`End` не двигают.
- Курсор после эмодзи из суррогатной пары — не разрывать.
- Выделение через несколько строк включает переводы строк: копия вставляет с `\n`.
- Выделение и ghost: при выделении ghost скрыт.
- Клик по номеру строки — не реализуем (v1).

## Критерии готовности

- [ ] Стрелки по русскому тексту идут по буквам, не по байтам.
- [ ] Эмодзи не ломается, курсор не «застревает» внутри.
- [ ] Двойной клик по слову с дефисом/подчёркиванием выделяет нужное.
- [ ] Drag за границу окна скроллит и продолжает выделять.
