# M10 - переходы по ссылкам и Ctrl+клик

Статус: **план, не начато**. Цель - «навёл/ткнул и перешёл»: переменная → объявление,
URL → браузер, заголовок/ссылка Obsidian → нужная заметка. Всё через мышь с `Ctrl`,
плюс клавиатурный паритет там, где он уже есть или нужен.

## Что хотим

| Жест | Куда | Поведение |
|---|---|---|
| `Ctrl` + клик по переменной/функции/типу | LSP definition | открыть файл (или текущий), поставить курсор в объявление; если несколько - список |
| `Ctrl` + клик по `http(s)://…` | браузер | `xdg-open` только для явно разрешённых схем |
| `Ctrl` + клик по `[[Note]]` / `[[Note#Heading]]` | Obsidian | открыть заметку/заголовок в vault |
| `Ctrl` + клик по `# Заголовок` в markdown | Obsidian | открыть текущую заметку на этом заголовке |
| `Ctrl` + клик по `[текст](url)` | браузер / файл | URL - браузер; относительный путь - открыть файл в pero |
| `Alt-d` (уже есть) | LSP definition | клавиатурный паритет для переменной |

Курсор при наведении с `Ctrl` - «рука»/подчёркивание ссылки, в статусе подсказка
`Ctrl+клик - перейти`. Без `Ctrl` клик остаётся обычной постановкой курсора.

## Решения (предлагаемые)

| # | Решение | Почему |
|---|---|---|
| 1 | Ctrl+клик по идентификатору = существующий `lsp.definition` в позиции клика | не плодим второй путь; LSP уже умеет несколько location |
| 2 | URL открываем только `http`/`https` | `file:`, `javascript:`, `data:` - не для редактора |
| 3 | `xdg-open` без shell, аргументом | никакой инъекции через текст файла |
| 4 | Obsidian vault ищем вверх по `.obsidian`, путь можно задать в конфиге | работает и в проекте, и в личном vault |
| 5 | Заголовок - только markdown-файл внутри vault | вне vault это просто текст, не угадываем |
| 6 | Ctrl+клик не запускает drag/выделение | иначе конфликт с обычным выделением мышью |
| 7 | Если LSP не запущен/не умеет definition - тост, без «тихого» клика | понятная обратная связь |
| 8 | Все переходы - команды реестра (`link.open`, `lsp.definitionAt`) | паритет «мышь = клавиша/палитра» |

## Открытые вопросы

- `Ctrl+клик` на заголовке: открывать Obsidian или сначала показывать mini-popup
  «открыть заметку / скопировать ссылку»? Пока plan: сразу Obsidian.
- Нужен ли `Ctrl+клик` по локальному пути (`./docs/x.md`, `../main.go`)? Хочется,
  но это отдельный тип ссылки; в v1 M10 - URL + Obsidian, локальные пути - после.
- Obsidian URI с заголовком: проверить точный формат (`file=Note%23Heading` vs
  `heading=…`) на живом Obsidian; до проверки не кодировать вслепую.
- Внешний браузер: `xdg-open` или `$BROWSER`? Решить в пользу `xdg-open` с
  fallback на `$BROWSER`.

## Конфиг (черновик)

```toml
[links]
# Открывать URL в браузере по Ctrl+клику.
browser = true
# Команда; пусто - xdg-open / $BROWSER.
browser_command = ""
# Obsidian: "auto" - искать .obsidian вверх; "" - выключить; путь - явно.
obsidian = "auto"
# Открывать заголовки текущей заметки в Obsidian.
obsidian_headings = true
```

`[keys]`:
```toml
"Alt-d" = "lsp.definition"   # уже есть
# "Alt-Enter" = "link.open"  # клавиатурный вариант для ссылки под курсором
```

## Безопасность и края

- URL/пути из текста - недоверенные: не выполнять shell, не открывать `file:`,
  `javascript:`, `data:`, `vbscript:`. Только `http`/`https`.
- Obsidian-путь: нормализовать, не выходить за vault (`..`), не открывать
  произвольные файлы по `[[../../etc/passwd]]`.
- Ctrl+клик по перенесённой строке softwrap - сначала экранная координата → руна,
  как обычный клик.
- Ctrl+клик вне ссылки/идентификатора - обычная постановка курсора, не тост.
- Ссылка в diagnostic/ghost слое не кликабельна - только настоящий текст.
- `read-only` не мешает переходам.
- Если файл уже открыт - переключить вкладку, не дублировать.
- Если definition в другом файле - открыть в новой/пустой вкладке по общим правилам.
- Если браузера/Obsidian нет - error-тост, редактор жив.

## Тесты

- `links_test.go`: URL в строке, `[[Note]]`, `[[Note#Heading]]`, `# Heading`,
  `[text](url)`, экранирование, кириллица, несколько ссылок в строке.
- hit-test: колонка до/внутри/после ссылки; softwrap; tab.
- Ctrl+клик по идентификатору вызывает definition с позицией клика (фейковый LSP).
- `xdg-open` не вызывается для `javascript:`/`file:`; для `https://` вызывается
  с одним аргументом (fake-бинарь в PATH).
- Obsidian URI: vault auto-detect, путь с пробелами/кириллицей, заголовок,
  отказ при выходе за vault.
- Ctrl+клик не меняет выделение и не начинает drag.
- Клавиатурный `link.open` на ссылке под курсором.

## Критерии готовности

- [ ] Ctrl+клик по `fmt.Println` в `.go` открывает объявление (или список).
- [ ] Ctrl+клик по `https://…` открывает браузер, а `javascript:` - нет.
- [ ] Ctrl+клик по `[[Note]]` в vault открывает Obsidian-заметку.
- [ ] Ctrl+клик по `# Заголовок` открывает заметку на заголовке (или тост,
      если Obsidian не настроен).
- [ ] Без Ctrl обычный клик/драг работают как раньше.
- [ ] `go test ./...`, `-race`, PTY-сценарий с fake `xdg-open`/Obsidian.

## Порядок работ

1. `links.go`: распознавание ссылок + тесты (без UI).
2. Ctrl+клик → LSP definition (самое полезное и уже почти готово).
3. URL → `xdg-open` + валидация схем.
4. Obsidian vault auto-detect + URI + заголовки.
5. Клавиатурный `link.open`, статус-подсказка, docs.
